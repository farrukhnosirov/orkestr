# Джарвис: шаблонные ответы и режим разговора

Решение и архитектура — [ADR-0049](adr/0049-jarvis-persona-and-conversation-mode.md).

## Как Джарвис выбирает ответ

На каждую фразу (голосом или текстом в режиме «Ассистент»), если это не
команда Orkestr («статус проекта», «останови проект») и не ответ «да/нет» на
открытое подтверждение:

1. **Действия Джарвиса** из базы: «режим разговора», «режим команд»,
   «забудь разговор», «называй меня босс», «замолчи», «повтори».
2. **Команда компьютера** (каталог из 1000+ команд, свои наборы) — выполняется,
   ответ в стиле Джарвиса: «Открываю YouTube, сэр.»
3. **Шаблонный ответ** из локальной базы — мгновенно и без токенов.
4. **Режим разговора** — ответ ИИ (модель из настроек Джарвиса, по умолчанию
   модель ИИ-менеджера с резервной цепочкой провайдеров). Текст идёт потоком,
   озвучивается по предложениям. Если ИИ понял, что нужно сделать действие,
   он передаёт команду (`<<run: открой youtube>>`) — она выполняется.
5. **Режим команд** — незнакомую задачу разбирает ИИ-планировщик (как раньше);
   в режиме «Оркестр» вопрос уходит Менеджеру проекта.

## База шаблонов

* Источник: `scripts/gen-jarvis-dialog.mjs` (категории, шаблоны фраз, ответы).
* Данные: `crates/computer/data/dialog.json` (≈0,8 МБ) и отложенная выборка
  `crates/computer/data/dialog-heldout.json` (не входит в базу).
* Пересборка: `node scripts/gen-jarvis-dialog.mjs`; проверка, что данные
  актуальны: `node scripts/gen-jarvis-dialog.mjs --check`.

| Показатель | Значение |
|---|---|
| Тем (интентов) | 108 в 14 категориях |
| Уникальных формулировок вопросов | **15 405** |
| Дополнительно — варианты с опечатками | 796 |
| Вариантов ответов | 336 (с подстановками) |
| Отложено для проверки точности | 2 590 фраз (1 391 чистых + 1 199 с опечатками) |

**Как считаются формулировки.** Фраза считается один раз по нормализованной
форме: нижний регистр, `ё → е`, без знаков препинания, без слов-паразитов и
обращений, которые не меняют смысла (пожалуйста, джарвис, ну, слушай, а, бро,
дружище…). Поэтому «Джарвис, привет!», «ну привет» и «привет» — это **одна**
формулировка. Варианты с опечатками считаются отдельно и в 15 405 не входят.
Одна и та же формулировка не может принадлежать двум темам (генератор
отбрасывает такие совпадения).

**Подстановки в ответах:** `{address}` (", сэр" / ", босс" / ", имя" / ""),
`{Address}`, `{time}`, `{date}`, `{date_full}`, `{weekday}`, `{tomorrow}`,
`{yesterday}`, `{month}`, `{year}`, `{days_to_ny}`, `{weekend}`, `{greeting}`,
`{coin}`, `{dice}`, `{number}`, `{last}` — вычисляются в момент ответа.
Варианты чередуются и не повторяют предыдущий.

**Точность сопоставления** (`cargo test -p orkestr-computer --test dialog`):

| Проверка | Результат | Порог теста |
|---|---|---|
| Отложенные перефразировки → верная тема | **98,4 %** (1 369 / 1 391) | ≥ 95 % |
| Отложенные перефразировки с опечатками | 76,7 % (920 / 1 199) | ≥ 70 % |
| Фразы команд каталога, принятые за болтовню | **0** из 626 | ≤ 1 % |
| Посторонние вопросы (ИИ должен отвечать сам) | **0** ложных срабатываний из 34 | 0 |
| Время сопоставления | ≈ 3 мс (debug-сборка) | < 400 мс |

## Настройки (Настройки → Джарвис)

Характер Джарвиса вкл/выкл, обращение (сэр / босс / по имени / без
обращения), имя, приветствие при запуске, мгновенные ответы без ИИ, модель
для разговора, память разговора (2–60 сообщений), знание о проектах,
«Забыть разговор». История разговора хранится только на этом компьютере.
